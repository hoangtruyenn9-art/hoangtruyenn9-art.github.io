Privacy policy

Last updated: 10 November 2026

TRUYEN VIRAL AUTO is a private desktop tool used only by its owner, on the owner's own computer.

Google data the tool uses

  • Google Drive (drive.file): creates and manages only the files and folders the tool itself uploads to the owner's Drive. It cannot see any other Drive files.
  • Gmail (gmail.send): sends report emails from the owner's account to the owner. It cannot read the mailbox.

What is collected or shared

Nothing. The tool collects no data about anyone else, sends no data to the developer or third parties, and runs no analytics. Sign-in tokens are stored only in the owner's macOS Keychain on the owner's computer.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions.
